# AppTeamCarolina.com

Static marketing site for App Team Carolina.

## Structure

```
index.html              — Main landing page
css/
  style.css             — Primary styles
  normalize.min.css     — CSS reset
js/
  main.js               — Site scripts
assets/                 — Images, icons, and SVGs
bubbly/                 — Bubbly app page (privacy, terms, support)
centible/               — Centible app page
bootcamp-announcement/  — Bootcamp announcement page
```

## Running Locally

Open `index.html` directly in a browser, or use a static file server:

```bash
npx serve .
```

## Deployment

Deployed via GitHub Pages. The `CNAME` file handles the custom domain.
